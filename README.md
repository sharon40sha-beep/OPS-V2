# OPS-V2

PWA לניהול תנועת נכסים מאובטחת עם מנוע הגרלה אוטומטי נגד מדפסיות.
React + Vite + TypeScript, Supabase (Postgres) כ-backend.

## הקמה

1. **DB** — הרץ ב-Supabase SQL Editor, לפי הסדר, את כל הקבצים ב-`supabase/migrations/` (0001 → … → 0005).

### מוסכמה ל-migration חדש
כל migration מתחיל, בתוך ה-transaction, ב:
```sql
select app_private.reset_data_if_pre_pilot();
```
עד שהמנהל לוחץ "הכרז תחילת פיילוט" (הגדרות) — זה מוחק נסיעות והיעדרויות. אחרי ההכרזה
(`app_settings.pilot_start_date`, נעול לשינוי) — לא נוגע בנתונים.
2. **Env** — `cp .env.example .env`
3. `npm install && npm run dev`

Build לפרודקשן: `npm run build` → תיקיית `dist/` (סטטית, כל hosting).

## אבטחה

- הדפדפן משתמש רק ב-publishable key. RLS מופעל על כל הטבלאות **ללא policies**, ול-anon אין הרשאות טבלה —
  כל גישה עוברת דרך RPCs מסוג `SECURITY DEFINER` שמאמתים session token.
- קודים מוצפנים ב-bcrypt (pgcrypto). tokens נשמרים בשרת כ-SHA-256 בלבד.
- 3 ניסיונות כושלים (התחברות או step-up) → נעילה ל-30 דקות + ניתוק כל הסשנים.
- Step-up PIN נדרש ל: בניית שבוע, מחיקת נסיעה, שחרור נעילה.
- סשן: idle של שעתיים בשרת; בצד הלקוח נמחק כשהאפליקציה ברקע ≥ 3 שניות
  (debounce נגד אירועי `visibilitychange` שגויים ב-Safari mobile).
- עובד רואה רק את הנסיעות שלו, פרטים מלאים רק להיום, ולעולם לא את `trip_type`.

- מדיניות קוד (נאכפת בשרת): לפחות 6 תווים, אות גדולה באנגלית, ספרה וסימן.

## מנוע ההגרלה (`admin_generate_week`)

לכל יום ב'–ו' ולכל נכס פעיל (ימים שכבר יש בהם נסיעה — מדולגים). עובדים שסומנו כנעדרים לא משובצים.
בריכת השיבוץ כוללת את כל העובדים הפעילים (כולל מנהלים), חוץ מהנהג הראשי.

0. כל נסיעה היא הלוך+חזור עם צוות אחד (`assigned_workers`) — אותם עובדים יוצאים וחוזרים עם המוצר.
   עובד "פנוי" = פעיל, לא נעדר, ולא משובץ כבר בנסיעה אמיתית אחרת באותו יום. אין עובד פנוי →
   לא נוצרת נסיעה, והמנהל מקבל "אין עובד פנוי ל-A1 ב-[תאריך] - נדרשת התערבות ידנית".
1. נהג ראשי משובץ כל יום (חוץ מהיעדרות): או ברכב חברה אמיתי (תמיד עם לפחות עובד אחד נוסף),
   או לבד בפיתוי (בלי מוצר). לכן רכב שאינו company מותר רק אם אפשר לייצר פיתוי באותו יום.
2. רכב: מתוך סוגים שלא מיצו מכסה חודשית ועומדים בכלל 1.
3. פרמטרים: יציאה תמיד מהחניה המקורה; אפשרויות שמסומנות "רק רכב חברה" (למשל יציאה מהמפעל
   דרך הכניסה הראשית) מוגרלות רק לרכב חברה.
4. אנטי-מדפסיות מול 10 הנסיעות האחרונות: אין שילוב זהה של רכב+יציאה+ציר+כניסה, ואין רכב
   ביותר מ-60% מאותו יום בשבוע (מ-4 דגימות). עד 10 ניסיונות, אחרת הכי פחות חוזר.
5. פיתוי (מקסימום 5 ב-10 האחרונות): רכב חברה, נהג ראשי לבד, ציר וכניסה שונים, חלון זמן הפוך,
   מקושר דו-כיוונית לנסיעה האמיתית.
6. `vehicle_budget.current_month_count` מסונכרן מטבלת הנסיעות (מקור אמת).
